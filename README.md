# **Диплом**

**App.py – web-приложение, которое считает количество обращений и записывает их в базу данных MySQL.**

**Инфраструктура для приложения:**

- Сеть, подсети.

- Группы безопасности для ВМ (принимает входящий трафик только на порты 22,80,443) и кластера SQL (принимает входящий трафик только на порт 3306 и только с наших виртуальных машин).

- ВМ для приложения.

- Managed SQL-кластер, хост и БД для приложения.

- Container Registry для хранения docker-образов приложения.

- S3 Bucket в качестве удаленного backend.

**Логика создания инфраструктуры:**

- Сначала создается Container Registry, затем собирается локально и пушится в CR docker-образ нашего приложения, только после этого создается остальная инфраструктура.

- Во время создания ВМ на нее устанавливается docker, пуллится образ приложения из CR и запускается контейнер.

- Если в файлах app.py, Dockerfile или docker-compose.yaml происходят изменения, образ пересобирается и отправляется в Container Registry.

- Пароль от БД храним в Lockbox, backend terraform в S3 Bucket.
  
- Для сборки и развертывания приложения используем Docker и Terraform. Ansible не применяем.

**Запуск приложения:**

Terraform apply
